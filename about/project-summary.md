# 学伴小管家 — 项目总结文档

## 项目概述
- **项目名称**：学伴小管家
- **参赛赛事**：TRAE AI 创造力大赛（2026.6.16 - 7.15）
- **赛道**：学习工作 + 社会公益（附加）
- **目标用户**：青少年学子（中学生、高中生、技校生等）
- **核心定位**：学习有节奏，情绪有出口 — AI 驱动的青少年学习压力管家
- **演示地址**：https://haixindu.github.io/study-buddy/
- **GitHub 仓库**：https://github.com/HaiXinDu/study-buddy.git
- **主文件路径**：`/workspace/study-buddy-demo/index.html`

## 技术架构
- **单文件 HTML 应用**，零外部依赖，浏览器直接打开即可运行
- **LocalStorage** 客户端数据持久化（隐私友好，无需后端）
- **Web Audio API** 白噪音生成（雨声、海浪、风声、篝火4种）
- **Web Audio API** 专注音乐合成（专注/冥想/唤醒3种模式）
- **Canvas API** 心情趋势图表 + 学习周报卡片
- **Pollinations.ai** 免费AI API（无需Key）+ 本地16场景智能回复双重架构
- **CSS变量** 驱动的暗黑模式
- **响应式设计** 移动端适配

## 功能模块（共7个Tab页面 + 2个Modal）

### 1. 首页仪表盘（Home）
- 个性化问候语（根据时间段）
- 每日一句（根据心情+时间段智能推荐）
- AI 关怀提示（根据心情连续低落提醒）
- 今日任务进度
- 学习统计（打卡天数、专注时长、任务完成率）
- 今日学习洞察
- 学习周报卡片（Canvas绘制，可保存为PNG）

### 2. 学习规划（Plan）
- 科目选择 + 考试日期 + 当前进度
- **AI 生成学习计划**（优先调用 Pollinations.ai 真实AI，失败回退模板）
- AI 生成的科目专属建议
- 任务勾选 + 完成状态持久化
- 计划统计面板

### 3. 情绪日记（Mood）
- 5级心情记录（很差→很好）
- 心情日记文本
- Canvas 心情趋势图表（带平均线）
- 打卡天数统计 + 连续打卡
- 心情历史记录列表

### 4. 番茄计时（Timer）
- 25分钟专注 + 5分钟休息
- 状态恢复（刷新页面不丢失计时状态）
- 专注次数统计
- 完成记录持久化
- 自动切换专注/休息模式

### 5. 减压放松（Relax）
- 呼吸练习（4-7-8呼吸法，带动画）
- 白噪音播放器（4种类型）
- **专注音乐播放器**（3种模式，Web Audio合成）
- **解压小游戏**（气泡点击，难度递增）

### 6. 成就徽章（Achieve）
- 10个成就徽章（初次打卡、坚持3天、坚持7天、首次专注、专注达人、计划达人、任务完成、全勤之星、游戏高手、音乐爱好者）
- 解锁动画 + 音效
- 进度条显示未解锁徽章的完成度
- 顶部统计（总数/已解锁/完成度）

### 7. AI 学习伙伴（AI Chat）
- **Pollinations.ai 真实AI对话**（免费无需Key）
- 精心设计的系统提示词（专门针对青少年学习/心理场景）
- 16个本地智能回复场景覆盖（压力、焦虑、复习、考试、记忆、英语、数学、语文、时间管理、睡眠、人际关系、家庭、手机、未来等）
- 4个快捷问题按钮
- 聊天气泡UI + 加载动画
- 对话历史记录（最近8轮）
- 10秒超时 + 自动fallback

### Modal
- 徽章解锁弹窗（带动画和音效）
- 学习周报预览弹窗（Canvas绘制，可下载PNG）

### 其他特性
- **暗黑模式**（手动切换 + 晚上10点-早上6点自动）
- **Toast 提示系统**
- **SVG Logo 图标**
